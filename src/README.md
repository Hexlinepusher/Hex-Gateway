# src/

| 文件或目录          | 职责                                                           |
| ------------------- | -------------------------------------------------------------- |
| main.js             | 读取配置，组合具体服务并监听 HTTP 端口。                       |
| service.js          | 具体上游服务的组合入口，提供人工模型、消费者和 execute。       |
| backend/            | 模板公共功能与服务接入约定，见 [后端说明](backend/README.md)。 |
| frontend/index.html | 保留空白前端页面。                                             |
