# design/

记录模板的架构、接口、数据结构和文件职责。

这里记录模板的设计约定与实现原理，不写逐步执行清单，也不归档任务的执行结果。

## 质量标准

合格的设计文档满足以下性质：

1. **陈述语气**: 定义句只作正面陈述；实例出现在定义之后的"例如"中
2. **术语统一**: 一个概念一个名字，正文只使用已定义的概念
3. **禁止防御性解释**: 写作过程中被淘汰的旧方案不得以辨析形式残留（那属于`history/`）
4. **不做越阶段预设**: 文档应根据开发阶段限制设计范围，不做过于理想化的越阶段预设
