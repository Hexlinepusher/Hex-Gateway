# data/

本地运行数据目录。目录说明纳入版本控制，运行数据保持忽略；Docker 将本目录挂载到容器的 `/app/data`。

- [模板使用说明](../DOCUMENTS/模板使用说明.md#本地测试模型)：测试记录的内容、命名与保存时机
- [适配需求清单](../DOCUMENTS/适配需求清单.md)：具体服务的数据与资源管理要求

## 文件组织

- **`test_history/`**：测试模型的请求记录，JSON 正文格式化后保存，首次保存时自动创建
- 具体服务需要的凭证、账号及其他持久化数据，由服务适配确定文件组织

运行统计保存在内存中，重启后清空。基础测试使用的临时数据位于 `.docs/trashcan/basic-test-*`。
