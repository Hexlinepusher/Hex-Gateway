# test/

模板的基础回归测试，使用 Node.js 测试运行器与本地模拟服务。

- [命令说明](../DOCUMENTS/Commands.md#检查)：测试与开发检查命令
- [模板使用说明](../DOCUMENTS/模板使用说明.md)：接口与运行规则

## 文件组织

- **[`basic.test.js`](basic.test.js)**：统一的基础测试，覆盖启动、HTTP 接口与鉴权、两种协议的测试响应及请求保存、消费者调度与超时、统计和控制台、统一日志与关闭流程

## 运行说明

在项目根目录执行 `npm test`。测试会启动临时 HTTP 服务和命令入口子进程，结束时完成清理。

测试产物保留在 `.docs/trashcan/basic-test-*`，不写入根目录 `data/`。前端相关断言覆盖页面与静态资源、概览操作顺序和失败后的恢复。
